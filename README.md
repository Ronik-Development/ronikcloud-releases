# RonikCloud Windows downloads

Official direct-download installer for RonikCloud on Windows x64.

[Download the latest Windows installer](https://github.com/Ronik-Development/ronikcloud-releases/releases/latest/download/ronikcloud-windows-setup.exe).

This Windows release is unsigned. Windows may show an unknown-publisher warning.
The installer includes the Microsoft C++ runtime libraries and installs for your
Windows user. Starting backups at sign-in is optional.

Sign in with your existing RonikCloud account, including an account with a plan
purchased on the web, to access your storage. A subscription is tied to your
account across supported platforms.

Each release includes a SHA256SUMS.txt file for verifying the installer download.
Visit [RonikCloud](https://ronikcloud.com) for the app and other platform downloads.
